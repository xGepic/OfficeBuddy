# Office Buddy

A German Windows desktop app that makes everyday PDF and image tasks simple for people who are not computer experts. It opens on a start screen with fifteen large tiles, one per task, grouped under four headings. Everything runs on the PC itself: nothing is uploaded, and the app never goes online.

| Tile | What it does |
|---|---|
| *PDF-Seiten ordnen* | |
| **Zusammenfügen** | Combine several PDFs into one, in the order you drag them into |
| **Seiten bearbeiten** | Rotate, reorder and remove Pages, and insert the Pages of other PDFs at a chosen place; blank backs of duplex scans are found automatically |
| **Seiten herauslösen** | Save selected Pages as a new PDF |
| **Aufteilen** | Split a PDF into several Parts |
| *PDF-Dateien bearbeiten* | |
| **Verkleinern** | Make a PDF small enough to send by email (under 10 MB, or 20 or 25 MB if set in Einstellungen), or split it into email-sized Parts |
| **Unterschreiben** | Put a photo or scan of one's signature on PDF Pages, its white paper made transparent; the signature is remembered for next time |
| **Text erkennen** | Read the text in a scanned PDF, to copy it or to save the PDF searchable with the text invisibly behind each Page |
| **PDF-Passwort** | Remove a PDF's password one knows, or give a PDF a password |
| **PDF reparieren** | Rebuild a damaged PDF, e.g. a broken download, as far as anything of it can be saved |
| *PDF und Bilder umwandeln* | |
| **Bilder zu PDF** | Turn phone photos and other JPG/PNG images into one PDF, one A4 Page each, the right way up |
| **PDF als Bild** | Save Pages as JPG images |
| *Fotos und Bilder* | |
| **Bildgröße ändern** | Make a photo or other JPG/PNG image smaller or bigger, by percentage or by width and height in pixels |
| **Bild zuschneiden** | Cut away the edges of a photo, such as the table around a photographed letter, and turn it in 90° steps |
| **Bild in Bild** | Put one image on top of a photo, such as a logo or a signature, and drag and size it into place |
| **Bilder nebeneinander** | Line up two or more images side by side or one below the other as one image, such as both sides of an ID card |

Every change can be undone until the result is saved, and saving always asks where to put the file, suggesting a sensible name next to the original.

**Einstellungen**, from the start screen, holds three choices, each saved at once:

- **Speichern unter** – the folder the save dialog opens in: next to the original (the default), Dokumente, Desktop or a folder of one's own.
- **Größe von E-Mail-Anhängen** – 10, 20 or 25 MB, the size Verkleinern gets PDFs under. 10 MB gets through almost anywhere.
- **Favoriten** – Tools whose tiles the start screen shows first.

## Getting it onto a PC

Build a single `OfficeBuddy.exe` that runs without installing:

```
dotnet publish src\OfficeBuddy.App -c Release -o artifacts\single -p:PublishSingleFile=true -p:IncludeAllContentForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none
```

`artifacts\single\OfficeBuddy.exe` contains everything the app needs, so nothing else has to be installed. Copy it to the PC and put a shortcut on the desktop; to update, replace the exe with a newer one. It unpacks itself into a temporary folder on its first start, which takes a few seconds; later starts are quick.

Every push to `main` also builds it on GitHub, after the tests pass ([build-exe.yml](.github/workflows/build-exe.yml)), and puts it on the **latest** release: download `OfficeBuddy.exe` from **Releases** on the repository's front page. Each build replaces the one before.

## Development

Needs Windows 10 (2004) or later and the .NET 10 SDK.

```
dotnet build                                   # everything
dotnet run --project src\OfficeBuddy.App       # start the app
dotnet test                                    # all tests
```

The solution is [OfficeBuddy.slnx](OfficeBuddy.slnx):

- **[src/OfficeBuddy.Core](src/OfficeBuddy.Core)** – all PDF and image logic. Each tile has a *session* (for example `CompressSession`) that holds the complete state of its screen, with undo/redo, and saves the result.
- **[src/OfficeBuddy.App](src/OfficeBuddy.App)** – the WinUI 3 screens. They stay thin and call the sessions. All German texts are in [Strings/de-DE/Resources.resw](src/OfficeBuddy.App/Strings/de-DE/Resources.resw), the blue look in [Themes/Blue.xaml](src/OfficeBuddy.App/Themes/Blue.xaml).
- **[tests/OfficeBuddy.Core.Tests](tests/OfficeBuddy.Core.Tests)** – xUnit tests that act like a user through the sessions and check the files written. Sample PDFs and images are generated by the tests themselves.
- **[third_party/Ghostscript](third_party/Ghostscript)** – the bundled Ghostscript that Compress uses.

The screens are not tested automatically; check them by hand.

### Libraries

- [PDFsharp](https://www.pdfsharp.com/) 6.2 (MIT) builds the PDFs. Stay on 6.2: from 6.5 on it is AGPL with a licence check.
- `Windows.Data.Pdf`, built into Windows, draws Pages for thumbnails, the preview, Page to image and blank-page detection.
- `Windows.Media.Ocr`, built into Windows, recognises text for Text erkennen. It needs a Windows language with text recognition, which a German Windows has.
- [Ghostscript](https://ghostscript.com/) 10.06 (AGPL), run as a separate program, compresses PDFs, takes passwords off and rebuilds damaged files. Its licence is why the whole app is AGPL (see [Licence](#licence)).
- [PdfPig](https://github.com/UglyToad/PdfPig) reads PDFs back in the tests, and [Xunit.SkippableFact](https://github.com/AArnott/Xunit.SkippableFact) skips the text recognition tests where Windows can't recognise text.
