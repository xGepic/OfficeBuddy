# One Tool per tile, not a shared page workspace

The app opens on a start screen of tiles, and each tile leads to its own Tool screen that runs from opening a Document to saving the result. We rejected a single workspace where all Pages of all open Documents can be edited together. That design is more powerful, but the users asked for clearly separated, single-purpose screens. The one exception is *Seiten bearbeiten*, which combines Remove pages, Rotate and Reorder, because those three are nearly always needed together on the same scan. Insert pages joined them later: an inserted Page usually needs turning, moving or trimming right away, too.
